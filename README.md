# Re-Eng

الموقع نسخة JavaScript ثابتة، من غير قاعدة بيانات أو سيرفر. الطلبات والصور بتتخزن في مساحة المتصفح على الجهاز باستخدام IndexedDB.

## النشر على Vercel

مجلد `public/` هو الموقع، وملف `vercel.json` مضبوط لنشره كما هو.

1. افتح [Vercel](https://vercel.com/new).
2. اختار **Add New → Project**، واستورد مستودع `arabdalla88/Re-Eng`.
3. اضغط **Deploy**. مش محتاج متغيرات سرية أو إعداد قاعدة بيانات.
4. بعد النشر افتح رابط الموقع.

## مهم: إيه معنى التخزين المحلي؟

كل طلب يفضل في **نفس المتصفح وعلى نفس الجهاز** اللي اتبعت منه. مفيش مزامنة مع أجهزة الزوار أو كمبيوتر الأدمن، ومسح بيانات المتصفح ممكن يمسح الطلبات. لوحة الأدمن مفيهاش تسجيل دخول في وضع التجربة، فلا تستخدمها لاستقبال بيانات حقيقية أو خاصة.

ده مناسب لمعاينة شكل الموقع وتجربة الفورم والكتالوج على جهاز واحد. عشان كل الناس تبعت طلباتها وتظهر للأدمن على جهاز مختلف، لازم خدمة تخزين مشتركة — ده مش ممكن بموقع ثابت فقط.

## معاينة محلية والاختبارات

```powershell

```
